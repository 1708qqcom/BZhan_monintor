# Feature Requirements - 多用户隔离系统

## Background

当前系统是单用户架构，所有访问者共用一个B站账号，看到相同的UP主列表。用户A扫码登录后，用户B访问系统也会看到用户A的账号数据，无法实现个人空间隔离。

**现状问题**：
- 所有用户共享一个Web后台密码
- 所有用户共享同一个B站账号（auth表只有一条记录）
- 用户无法维护自己关注的UP主列表

---

## Goal

实现多用户隔离，每个用户拥有独立的个人空间：
- 不同用户通过注册/登录访问系统
- 每个用户扫码绑定自己的B站账号
- 每个用户只能看到自己关注的UP主列表
- 用户间数据完全隔离（管理员可查看所有数据）

---

## User Story

**As a** 普通用户  
**I want** 通过注册账号登录系统，扫码绑定我的B站账号  
**So that** 我能独立管理自己关注的UP主，不受其他用户影响

**As a** 管理员  
**I want** 查看所有用户的数据  
**So that** 我能监控和运维整个系统

---

## Functional Requirements

### FR-001 用户注册
- 用户可以通过用户名+密码注册账号
- 用户名唯一，不可重复
- 密码无强度要求
- 注册成功后自动登录

### FR-002 用户登录/登出
- 已注册用户可通过用户名+密码登录
- 登录成功后跳转到仪表盘
- 支持退出登录

### FR-003 B站账号绑定
- 每个用户可以扫码绑定自己的B站账号
- 绑定成功后，Cookie关联到该用户
- 同一用户可重新扫码更换绑定账号

### FR-004 关注列表同步
- 用户点击"同步关注"时，获取该用户绑定的B站账号的关注列表
- 同步结果写入该用户的数据空间
- 每个用户最多监控N个UP主（从配置读取）

### FR-005 UP主列表查看
- 普通用户只能看到自己关注的UP主列表
- 管理员可以看到所有用户的UP主列表（增加用户筛选）

### FR-006 推送历史查看
- 普通用户只能看到自己关注UP主的推送历史
- 管理员可以看到所有用户的推送历史

### FR-007 监控线程改造
- 监控线程轮询所有用户的B站账号
- 为每个用户独立检测新视频并推送
- 某用户B站账号过期不影响其他用户

### FR-008 管理员权限
- 管理员可以查看所有用户的UP主列表
- 管理员可以查看所有用户的推送历史
- 管理员可以查看所有用户的配置

## User Flow

### 用户注册流程
```
访问首页 → 点击"注册" → 填写用户名+密码 → 提交注册 → 自动登录 → 跳转仪表盘
```

### 用户登录流程
```
访问首页 → 填写用户名+密码 → 提交登录 → 验证成功 → 跳转仪表盘
```

### B站账号绑定流程
```
登录后 → 进入"登录管理"页 → 点击"扫码登录" → 显示二维码 → 手机扫码确认 → 绑定成功 → 自动同步关注列表
```

### 同步关注列表流程
```
进入UP主管理页 → 点击"同步关注" → 调用B站API → 写入当前用户的数据空间 → 显示同步结果
```

## Edge Cases

### EC-001 用户未绑定B站账号
- 访问UP主管理页面时，提示"请先绑定B站账号"
- "同步关注"按钮禁用

### EC-002 用户B站账号过期
- 监控线程跳过该用户，不执行检查
- 界面显示"账号已过期，请重新扫码"

### EC-003 用户名已存在
- 注册时提示"用户名已存在"
- 建议更换用户名

### EC-004 密码错误
- 登录时提示"用户名或密码错误"
- 不区分"用户名不存在"和"密码错误"

### EC-005 用户删除
- 用户删除时，级联删除该用户的所有数据（UP主、视频记录、登录信息）
- 或保留数据，标记为"已删除用户"

## Acceptance Criteria

### AC-001 用户注册
**Given** 访问者未注册  
**When** 提交注册表单（用户名+密码）  
**Then** 创建用户记录，自动登录，跳转仪表盘

### AC-002 用户隔离
**Given** 用户A和用户B都已注册  
**When** 用户A扫码绑定B站账号，同步关注列表  
**Then** 用户B看不到用户A的UP主列表

### AC-003 B站账号绑定
**Given** 用户已登录Web后台  
**When** 扫码绑定B站账号  
**Then** Cookie关联到当前用户，其他用户不受影响

### AC-004 管理员查看所有数据
**Given** 用户是管理员  
**When** 访问UP主管理页  
**Then** 可以切换查看所有用户的UP主列表

### AC-005 监控线程多用户
**Given** 用户A和用户B都已绑定B站账号  
**When** 监控线程运行  
**Then** 分别检查用户A和用户B的UP主新视频

---

## Out of Scope

- 用户邮箱验证
- 用户头像上传
- 密码重置功能
- 用户权限细分（只区分普通用户和管理员）
- 多B站账号绑定（一个用户只能绑定一个B站账号）
